  # project descripion
  This project demonstrates the performance comparison of Bubble Sort, Merge Sort, and Quick Sort algorithms. Users can input custom arrays or generate random arrays to analyze sorting efficiency. The system measures execution time, displays theoretical time complexities, identifies the fastest algorithm, and presents the results through an interactive chart. The project was developed as part of the Data Structures course to understand algorithm analysis and performance evaluation.
